## Platform

web

## Product Purpose

Leið is a browser DAW that turns public transport routes into music. Each line is a lane and each station contributes a note. Music comes first.

## Users

The user guide serves new users first, followed by a complete feature reference. This audience order was confirmed by the project owner.

## Capabilities and Constraints

The existing Next.js application supports seven cities, route-based composition, instruments, effects, automation, drums, saved presets, exports and Song Chainer. City playback currently uses mock data; Live is disabled. Some features require an account, Pro access or deployment configuration.

## Brand Commitments

Preserve the Leið name and existing Night Timetable design system in DESIGN.md. The guide extends the existing application.

## Evidence on Hand

CLAUDE.md, the application source and lib/billing/plans.js are the guide's product sources. Guide content must describe shipped controls and label optional functionality.
